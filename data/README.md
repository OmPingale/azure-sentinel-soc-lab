# Data Folder

This folder is reserved for sanitized lab exports.

Recommended file to upload:

- `failed-rdp-logons-export-1000.csv`

Recommended columns:

- `TimeGenerated`
- `Account`
- `Computer`
- `IpAddress`
- `Activity`
- `EventID`

Do not upload files containing credentials, tenant IDs, subscription IDs, private keys, billing data, or personal account information.
